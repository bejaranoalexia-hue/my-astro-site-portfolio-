## What this is for

Search traffic is wasted when it lands in a form that sits for two days. SEO and answer-engine work here is built to feed the same speed-to-lead system as Google LSA and paid ads.

## How it usually runs

Ongoing, with a four-week setup. First the query set that actually converts, then pages and answers, then the same intake path as the rest of the pipeline.

## What you get

A prioritized query set, published pages, and traffic that hits a queue built to respond immediately.
